# 🛍️ Interface Frontend E-Commerce Responsive

Un projet frontend moderne et responsive pour e-commerce développé avec HTML, CSS et JavaScript.  
Le site inclut un changement dynamique de couleurs, un design adaptable à tous les appareils et une interface moderne axée sur l’expérience utilisateur.

## ✨ Fonctionnalités

✅ Mise en page entièrement responsive  
✅ Changement dynamique de thème  
✅ Interface moderne et intuitive  
✅ Navigation fluide  
✅ Design adapté mobile, tablette et desktop  
✅ Structure propre et réutilisable  
✅ Animations fluides en JavaScript  
✅ Expérience utilisateur interactive

---

## 🛠️ Technologies utilisées

- HTML5  
- CSS3  
- JavaScript  
- Flexbox  
- CSS Grid  
- Bootstrap  

---

## 📱 Responsive Design

Le projet utilise des techniques modernes de responsive design pour garantir une excellente expérience sur :

- Smartphones  
- Tablettes  
- Ordinateurs portables  
- Écrans de bureau

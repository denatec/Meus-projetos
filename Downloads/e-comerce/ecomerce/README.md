# 🛍️ E-Commerce Responsive Frontend (pt)

Um projeto de frontend moderno e responsivo para e-commerce desenvolvido com HTML, CSS e JavaScript.  
O site possui troca dinâmica de cores, design adaptável para diferentes dispositivos e uma interface moderna focada em experiência do usuário.

## ✨ Funcionalidades

✅ Layout totalmente responsivo  
✅ Troca dinâmica de cores do tema  
✅ Interface moderna e intuitiva  
✅ Navegação fluida  
✅ Design adaptado para mobile, tablet e desktop  
✅ Estrutura organizada e reutilizável  
✅ Animações suaves com JavaScript  
✅ Experiência visual interativa

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- bootstrap

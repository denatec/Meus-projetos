# 🛍️ E-Commerce Responsive Frontend

A modern and responsive e-commerce frontend project built with HTML, CSS, and JavaScript.  
The website includes dynamic theme color switching, responsive design for all devices, and a clean modern UI focused on user experience.

## ✨ Features

✅ Fully responsive layout  
✅ Dynamic theme color switching  
✅ Modern and intuitive interface  
✅ Smooth navigation  
✅ Mobile, tablet, and desktop friendly design  
✅ Clean and reusable structure  
✅ Smooth JavaScript animations  
✅ Interactive visual experience

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Flexbox  
- CSS Grid  
- Bootstrap

## 📱 Responsiveness

The project is designed using modern responsive techniques to ensure a great experience on:
